# No-Go Gates

The migration must stop if any of these remain unresolved:

- Auth/password compatibility unresolved
- UUID mismatch
- Missing schema required by application code
- `learning_facilities` definition/state still unknown
- Missing RLS, policies, functions, or triggers
- Permission mismatch
- LINE mapping integrity failure
- Candidate side-effect isolation incomplete
- Ubuntu server still requires periodic human internet login
- HTTPS/inbound access not proven
- No off-server backup
- Backup restore not tested
- Application build/tests failing
- Candidate restart recovery failing
